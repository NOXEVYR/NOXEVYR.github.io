六个新方向。

01—04 可用模板 / 05—06 互动案例

01Bronx

免费模板 · Framer
综合作品集 · 优先看黑白 / 大标题 / 项目索引

极简作品集，有明暗两种方向。适合在同一个网站里组织软件、影像和游戏，作品画面可以成为主角。

放到你的网站：推荐作为整体结构参考：主页放精选作品，软件保留清楚的版本、平台和下载；影像与游戏使用各自的详情页。

打开完整体验 ↗官方模板页 ↗

02Palette

付费模板 · Framer
复古影像 · 个性优先复古 / 大字号 / 编辑排版

摄影与创意作品导向，强调大画面、复古视觉和杂志式编排。如果你更想突出个人气质，这个方向很值得看。

放到你的网站：可以延续你的向日葵网站标志，加入温暖的底色与影像封面。软件区仍保留简洁目录，需要准备质量较好的作品画面。

打开完整体验 ↗官方模板页 ↗

03Cinematic

付费模板 · Webflow
电影作品集深色 / 视频 / 项目故事

面向导演和视频创作者的深色作品集，提供背景视频与媒体灯箱。影像数量增加后，可以借鉴它的片单和播放体验。

放到你的网站：适合未来的「影像」栏目。首页保留轻量封面，点击后播放；软件目录不必全部改成电影宣传页。

打开完整体验 ↗官方模板页 ↗

04Polygon

付费模板 · Framer
游戏与互动作品游戏 / 粒子 / 滚动叙事

针对游戏开发与互动媒体设计，带鼠标响应粒子、视频预览和滚动展示。适合将一款重点游戏做成有氛围的专题。

放到你的网站：推荐借鉴游戏详情页，而不是照搬工作室宣传结构。为每款游戏放预告片、操作说明、平台和试玩按钮。

打开完整体验 ↗官方模板页 ↗

05Lusion

真实网站 · 非模板
互动工作室案例动态 / 三维 / 沉浸画面

将三维、动态影像和互动开发放进同一个作品体系，适合观察如何让不同类型的作品保持统一的视觉气质。

放到你的网站：借鉴精选作品的画面比例、动效节奏和过渡即可。完整三维首页的开发与性能维护成本更高。

06Bruno Simon

真实网站 · 非模板
可以玩的个人网站三维世界 / 驾驶 / 探索

访客驾驶小车探索个人作品。它展示了网站本身也能成为互动作品，是未来游戏栏目很有启发性的案例。

放到你的网站：建议作为「互动实验室」独立入口，主网站仍能直接查找软件与播放视频；这样手机和快速访问也更方便。
